# Thought Process — How AI Was Integrated Into the Workflow

AI was used as a supporting tool throughout the development process, with the main approach being **understand first, implement gradually, and verify before accepting the result**.

1. **Understand the project before implementation.**  
   AI was first used to understand the overall project requirements and the role of the `select` mechanism. This helped build an understanding of TCP echo servers, `select()`, socket operations, and how multiple clients are handled.

2. **Develop the implementation gradually.**  
   AI was used to understand the required steps and assist with developing the `select` server. The implementation was refined through multiple iterations while understanding the purpose of each part of the code.

3. **Use AI for debugging and problem solving.**  
   Potential issues in the implementation were discussed with AI to understand their causes and possible solutions. AI was also used to review the final implementation and identify possible errors or edge cases.

4. **Cross-check the generated work.**  
   Code and suggestions provided by AI were cross-checked using other AI tools and were also reviewed and verified by teammates. This helped identify issues that might not have been noticed during the initial development.

5. **Use AI for supporting tasks.**  
   AI was also used for common technical doubts and supporting tasks such as preparing the Makefile, README and other markdown files for the `select` server, while keeping them consistent with the project's requirements.

6. **Perform final verification.**  
   The implementation was compiled, tested, reviewed, and modified where necessary before being considered complete. AI was treated as an assistance tool, while the final decisions and integration were done by the team.
