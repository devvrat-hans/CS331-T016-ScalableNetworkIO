# AI Tools Used

## Gemini

Gemini was used throughout the project as a main assistant, from understanding the project requirements and networking concepts to planning and writing the `select`-based TCP echo server. It was also used for debugging, code refinement, testing, and resolving technical issues encountered during development.

## Claude

Claude was mainly used as a secondary tool for cross-verifying the code and checking the correctness of the implementation. It was also used to clarify technical concepts and help troubleshoot specific problems during development.

## ChatGPT

ChatGPT was mainly used for basic doubts about the project and for solving some problems encountered during development. It was also used to cross-verify the code and to help write some of the Markdown files.
